# Brief para Google Stitch

Use o modo **App** e o modelo **3.1 Pro**. Gere um sistema de telas coerente, não somente uma tela isolada.

```text
Crie o design de um aplicativo móvel financeiro premium chamado Finance Control.

Contexto: é um app pessoal de finanças e dívidas compartilhadas. O produto já possui uma versão desktop, mas este design deve ser mobile-first, pensado para toque e uso diário, sem parecer um dashboard web espremido.

Objetivo visual: sereno, confiável, moderno e humano. Evite aparência de banco genérico, excesso de gradientes, cards demais, neon, ilustrações decorativas e interfaces escuras pesadas. Priorize leitura rápida de valores, espaço em branco, hierarquia clara e acessibilidade.

Direção de marca:
- cor principal: verde petróleo/teal profundo;
- base clara levemente quente, superfícies brancas, textos em grafite;
- estados: positivo verde, alerta âmbar, negativo coral discreto;
- cantos arredondados moderados, sombras suaves e tipografia sans-serif legível;
- contraste AA; alvos de toque confortáveis; suporte previsto para dark mode.

Crie as seguintes telas Android/iOS em 390px de largura, todas com o mesmo design system:
1. Login: simples, acolhedor, e-mail, senha, entrar, recuperar senha e área para biometria após primeiro login.
2. Início: saudação curta, saldo disponível, resumo mensal de receitas/despesas, alertas relevantes, próximos pagamentos e ações rápidas. Não use gráficos grandes no topo.
3. Lançamentos: lista por data com valor, categoria e status; filtros; botão flutuante para novo lançamento.
4. Criar lançamento: formulário em bottom sheet com tipo receita/despesa, valor, descrição, categoria e data. Mostre estados de validação claros.
5. Planejamento: orçamento por categoria, progresso legível, metas e alerta de limite próximo.
6. Dívidas: pessoas, valores pendentes, status de pagamento e ação de registrar pagamento.
7. Relatórios: período selecionável, gráfico de tendência pequeno, categorias principais e insights explicados em linguagem simples.
8. Central de notificações: lista persistente, não lidas visíveis e navegação para o item relacionado.
9. Perfil e segurança: preferências de notificação, dispositivos conectados e sessões ativas.

Navegação: barra inferior com Início, Finanças, Dívidas, Relatórios e Conta; botão flutuante central para novo lançamento. Use bottom sheets para ações contextuais. Inclua estados vazios, carregamento e erro para Início, Lançamentos e Notificações.

Entregue um conjunto de telas com anotações breves de interação, componentes reutilizáveis e uma pequena página de design tokens (cores, tipografia, espaçamento, radius e estados).
```
